Link akun Riot kamu ke Discord

1

Login ke Riot Games

Klik tombol di bawah untuk membuka halaman login resmi Riot Games. Masukkan username & password kamu (termasuk 2FA jika ada).

🔐 Login dengan Riot Games
2

Kembali ke Halaman Ini

Setelah berhasil login, Riot akan redirect kamu ke playvalorant.com. Kembali ke tab ini dan klik tombol "Saya Sudah Login" di bawah.

🔒 Aman: Login dilakukan langsung di situs resmi Riot Games. Bot tidak pernah melihat password kamu.
3

Link Akun ke Discord

Sekarang klik tombol di bawah untuk mengambil token dari Riot dan otomatis menghubungkan akun kamu ke Discord bot.
